# Cómo agregar las fotos de nosotros

Todo este sitio ya está listo para mostrar fotos de ustedes dos. Mientras
no existan los archivos, cada espacio simplemente muestra un ícono de
cámara — no rompe nada. En cuanto guardes la foto con el nombre exacto en
esta carpeta (`img/nosotros/`), aparece sola al recargar la página.

## Portada (index.html)

```
img/nosotros/portada.jpg
```
La foto grande junto al texto de bienvenida. Recomendado: vertical o
formato 4:5, algo que se vea bien recortada al centro.

## Galería "Nuestros momentos" (index.html)

```
img/nosotros/galeria-1.jpg
img/nosotros/galeria-2.jpg
img/nosotros/galeria-3.jpg
img/nosotros/galeria-4.jpg
```
Cuatro fotos que aparecen como polaroids justo debajo de la portada.
Formato cuadrado (1:1) se ve mejor.

## Foto de cada día (pages/diaN.html)

```
img/nosotros/dia1.jpg
img/nosotros/dia2.jpg
img/nosotros/dia3.jpg
img/nosotros/dia4.jpg
```
Una foto distinta en el encabezado de cada rutina. También se ve mejor
en formato cuadrado.

## Detalle circular en cada ejercicio

```
img/nosotros/detalle-1.jpg
img/nosotros/detalle-2.jpg
img/nosotros/detalle-3.jpg
```
Un pequeño círculo con corazón que aparece arriba de cada tarjeta de
ejercicio, rotando entre estas tres fotos. Cualquier foto sirve, entre
más cerrada (una selfie, por ejemplo) mejor se ve en círculo pequeño.

---

Formato recomendado para todas: `.jpg`, menos de 500KB cada una, para
que el sitio siga cargando rápido en GitHub Pages.

Las fotos técnicas de los ejercicios (las que muestran cómo se hace cada
movimiento) siguen en `img/dia1/`, `img/dia2/`, etc. — esta carpeta
`img/nosotros/` es solo para las fotos de ustedes.
